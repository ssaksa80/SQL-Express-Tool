Saving runs Setup, which proves the connection, the staging permissions and the share before it writes anything. It needs an administrator. A SQL login is prompted for in the elevated console, never in this page.

Actions

Full install — read this first

  1. Create the folder below and share it from this host.
  2. Set up against that share using Windows authentication.
  3. Schedule every database on the instance, on the interval in Settings, as SYSTEM.
  4. Run one backup immediately, as SYSTEM, and report what it returned.

Every database is included, production ones too. And a share on this host is not an offsite copy — if this disk dies the backups die with it. Point Settings at a real file server when you have one.

Actions other than the self test raise a Windows administrator prompt. Their output appears below as it happens.
